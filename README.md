# Geometry Dash: Breeze

A Geode mod port of **Andrexel's** fanmade spinoff of Geometry Dash — now playable directly inside GD on **Windows** and **Android**.

---

## Features

- **12 original levels** ranging from Normal to hard Demon
- Custom music for every level
- All icons and colors unlocked
- Separate save file — your vanilla GD progress is untouched
- Custom loading screen and main menu branding
- Credits screen accessible from the main menu

## Installation

Install via the **Geode mod index** in-game, or manually place the `.geode` file in your mods folder.

Requires **Geometry Dash 2.2081** and **Geode 5.8.2+**.

## Incompatibilities

This mod is a total conversion and is incompatible with other fangame mods:

- Geometry Dash Lunar
- Geometry Dash Time Reborn
- Geometry Dash Odyssey
- Better Progression
- GDUtils
- Globed
- Hard Mode
- Redash
- Alpha's Geode Utils *(Android/iOS only)*
